\begin{abstract}
This document defines control, configuration and monitoring (CCM) interfaces
for DAPHNE, the PDS Calibration Box and the PDS Power-over-Fiber (PoF) laser
boxes between PDS, DAQ, Slow Controls and DPS. Each DAPHNE uses one shared
1\,Gb Ethernet connection. DAQ CCM requests run and timing-endpoint
configuration through the component integrated into the SC-provided external
OPC UA server. SC can use that path to recover timing and publish board
readiness. Hermes remains a separate service on the same link.

Configuration uses request/response; monitoring is published. DAQ opmon
receives firmware counters, timing state and applied readout configuration
from \code{daphne-server} through OPC UA.
SC monitors voltages, temperatures, fans, service
status and versions. The inventory comprises 42 FD-VD boards and 150 FD-HD
boards. Calibration and PoF controllers expose equipment control and published
monitoring through their own interfaces to OPC UA. DAQ data readout and optical
timing transport are outside this scope.
\end{abstract}
