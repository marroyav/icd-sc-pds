\begin{abstract}
This document defines the control, configuration and monitoring (CCM)
interfaces for DAPHNE, the Light Calibration Module and the PDS Power-over-Fiber
(PoF) laser boxes. Each hardware system has its own physical-interface,
service and protocol description. The responsibilities of PDS, Slow Controls,
DPS and DAQ apply to these interfaces.

Configuration and control use request/response; monitoring is published.
The scope covers detector control and monitoring used by SC and DAQ.
DAQ data readout and optical timing transport are outside this scope.
\end{abstract}
